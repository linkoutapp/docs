# LinkedIn tools. Run locally.

Linkout connects Node.js tools to a visible Chrome session that you sign in to yourself. The public [`linkout-scraper`](https://github.com/linkoutapp/linkout-scraper) package exposes profile reads, connections, message history, activity reads, and explicitly enabled actions.

Linkout keeps authentication on your device. It does not submit credentials, set LinkedIn cookies, use proxies, or accept browser-fingerprint overrides.

## Start here

1. [Check the requirements](/getting-started/requirements).
2. [Install the package](/getting-started/installation).
3. [Sign in manually](/getting-started/authentication).
4. [Run one source-verified action](/getting-started/first-action).

:::warning Platform risk
Local execution through a visible browser does not guarantee account safety, policy compliance, or selector stability. Stop when LinkedIn presents a login, checkpoint, CAPTCHA, automation warning, restriction, or unexpected modal.
:::
